# AI 群聊机器人

## 工作原理

项目使用 [Telethon](https://github.com/LonamiWebs/Telethon) 库，让多个 AI 角色以**真实 Telegram 用户账号**（非 Bot）登录，在指定群组中自动接话、互相聊天、定时发起话题。

采用 AI Town 单协调器模式：
- 所有角色同时监听群消息
- 消息统一进入队列
- 协调器随机（或按策略）指定一个角色回复
- 避免多角色同时抢答

---

## 项目文件

| 文件 | 说明 |
|------|------|
| `main.py` | 根目录启动入口，内部转到 `chat_app/main.py` |
| `ui.py` | Web 配置界面根目录启动入口，内部转到 `chat_app/ui/` |
| `chat_app/characters.py` | 角色配置读取与默认角色定义 |
| `chat_app/behavior.py` | 回复策略、重复检测、上下文拼装 |
| `chat_app/session_manager.py` | Session 文件管理 |
| `scripts/check_groups.py` | 命令行查看已登录账号可见群组 |

## 回复策略

在 Web 配置页「回复行为」中可调整：

| 参数 | 说明 |
|------|------|
| 始终回复 | 每条消息都回复（否则按概率） |
| 回复延迟 | 发送前等待时间（秒） |
| 真人冷却时间 | 同一真人发消息后的最短回复间隔 |
| AI 互聊冷却时间 | AI 角色之间互相回复的最短间隔 |
| 回复分配策略 | 随机 / 轮询 / 最久未发言 |
| 互动模式 | 混合 / 仅响应真人 / 仅 AI 互聊 |

---

## 自动话题

在「自动发话题」中可设置：

- **话题间隔**：多久发一次新话题（默认 30 分钟）
- **启动等待**：Bot 启动后多久发第一条（默认 5 分钟）
- **话题方向**：限制话题的范围（娱乐、生活、热点等）

## 日志

运行日志写入 `logs/chat.log`，Web 页面底部可直接查看。

## 数据说明

| 文件/目录 | 内容 |
|-----------|------|
| `.env` | 所有配置（API Key、角色信息、回复策略等） |
| `sessions/` | 各 Telegram 账号的登录 session（敏感，勿上传）|
| `logs/chat.log` | 运行日志 |

---

## 安全提示

- `.env` 和 `sessions/` 包含敏感信息，不要提交到公开仓库
- 不要将 API Key、手机号、session 文件分享给他人
- 账号风控、限流、封禁等风险需自行承担，建议在小规模场景使用
