# 抽奖机器人

群内抽奖工具，支持一键参与按钮、管理员内定中奖人、自定义公告文案，操作全部在 Web 管理后台完成。

---

## 工作原理

- **抽奖 Bot**（`lottery_app/lottery_bot.py`）：独立进程，通过 Telegram Bot API 在群内发布公告、处理参与、公布结果
- **管理后台**（`lottery_ui.py`）：保留在根目录的 Streamlit 启动入口，页面实现位于 `lottery_app/lottery_ui.py`
- **数据存储**（`data/lottery.db`）：SQLite 数据库，Bot 和管理后台通过它共享数据

---

## 前期准备

### 1. 创建 Bot

1. 在 Telegram 找 `@BotFather`
2. 发送 `/newbot`，按提示填写 Bot 名称
3. 记录获得的 **Bot Token**（格式：`1234567890:AAxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx`）

### 2. 将 Bot 加入群组

1. 在群组内点「添加成员」，搜索你创建的 Bot 名称并添加
2. 在群组设置中将 Bot 设为**管理员**（需要发送消息权限）

### 3. 安装依赖

```bash
pip install -r requirements.txt
```

---

## 启动管理后台

```bash
streamlit run lottery_ui.py --server.port 8502
```

浏览器访问 `http://localhost:8502`

> `lottery_ui.py` 是保留在根目录的启动入口；后台页面会在需要时拉起 `lottery_app.lottery_bot` 进程。

## 操作流程

### 第一步：配置并启动 Bot

1. 打开管理后台 → **Bot 控制** Tab
2. 填入 Bot Token → 点「保存 Token」
3. 点「▶ 启动 Bot」

Bot 状态变为 🟢 运行中后即可操作。

---

### 第二步：创建抽奖活动

1. 打开 **创建/编辑活动** Tab
2. 填写：
   - **活动标题**（如：本周活动大抽奖）
   - **活动描述**（公告正文，支持 Markdown）
   - **目标群组 ID**（与 AI 机器人配置的群组 ID 相同）
   - **获奖公告模板**（`{winner}` 会被替换为中奖者名字）
3. 点「创建活动」，获得 **活动 ID**

---

### 第三步：（可选）设置参与口令

1. 打开 **参与条件 & 成员** Tab
2. 选择活动 → 填写参与口令（如：`抽奖参与`）
3. 保存后，用户需在群内发送该口令才能参与

> 不设置口令：用户点击公告下方的「参与抽奖」按钮即可参与。

---

### 第四步：拉取群成员（用于搜索内定人）

1. 在 **参与条件 & 成员** Tab 点「🔄 拉取成员」
2. 系统通过已有的 Telethon session 拉取群成员列表并缓存
3. 使用搜索框按名字或用户名快速查找成员

---

### 第五步：发布公告

在 Telegram 群内发送：

```
/start_lottery <活动ID>
```

例如：`/start_lottery 1`

Bot 将在群内发送公告消息，底部附带「参与抽奖 🎁」按钮。

---

### 第六步：（可选）设置内定中奖人

1. 打开 **内定 & 开奖** Tab
2. 选择活动
3. 选择「🎯 内定中奖人」
4. 在搜索框中找到目标成员，或直接填写用户 ID
5. 点「💾 保存内定设置」

> 如果内定的人没有参与抽奖，系统会自动降级为从参与者中随机选取。

---

### 第七步：开奖

**方式一：在群内发命令（即时）**

```
/draw <活动ID>
```

**方式二：在管理后台远程触发**

1. 打开 **内定 & 开奖** Tab
2. 查看当前参与者名单确认无误
3. 勾选确认框 → 点「🎉 立即开奖」
4. Bot 将在 5 秒内在群内发布结果

## 群内可用命令

| 命令 | 权限 | 说明 |
|---|---|---|
| `/start_lottery <id>` | 管理员 | 发布抽奖公告 |
| `/draw <id>` | 管理员 | 开奖并公布结果 |
| `/cancel_lottery <id>` | 管理员 | 取消活动 |
| `/lottery_status` | 所有人 | 查看当前活跃活动 |
| `/score` | 所有人 | 查询自己的积分余额 |
| `/leaderboard` | 所有人 | 查看积分排行榜 Top 10 |
| `/addpoints <用户ID> <分数>` | 管理员 | 手动给用户加分 |
| `/removepoints <用户ID> <分数>` | 管理员 | 手动给用户扣分 |

## 历史记录

在管理后台 **历史记录** Tab 中可查看：

- 历次抽奖的中奖者、参与人数、是否内定
- 展开查看完整参与者名单
- 导出 CSV

---

## 注意事项

- Bot 必须是群管理员，否则无法在群内发送消息
- 内定设置仅对管理后台可见，群内成员看到的是正常的开奖结果公告
- Bot 进程和管理后台是两个独立进程，可以分别启停
- 数据文件：`data/lottery.db`
- 日志文件：`logs/lottery_bot.log`
- PID 文件：`run/lottery_bot.pid`
